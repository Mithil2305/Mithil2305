## 🚀 What I'm Building

### 📊 [Yukti.pro — AI Business Intelligence](https://yukti.pro)
An AI-powered decision-intelligence product designed to help Indian small and medium businesses understand their numbers and decide what to do next.

- Turns business data into trends, forecasts, anomaly alerts, and practical recommendations.
- Focuses on everyday decisions around sales, inventory, margins, waste, and business performance.
- Working on a custom **3.8B-parameter Yukti model**, fine-tuned from Phi-3-mini-4k-instruct using LoRA.

**Tech:** Python · FastAPI · React · Vite · Firebase · LLM fine-tuning

### 🌿 [Wildlife Valparai — Biodiversity Community](https://www.wildlifevalparai.com)
A community platform for exploring, documenting, and protecting the biodiversity of Valparai and the Western Ghats.

- Community features for wildlife sightings, photography, blogs, exploration, and leaderboards.
- Extending the web experience into a React Native mobile app.
- Built around a TypeScript, Firebase, Cloud Functions, and Cloudflare R2 stack.

**Tech:** React Native · Expo · TypeScript · Firebase · Cloudflare R2

### 🚌 BusTrackNow — Community-Powered Bus Tracking
A public-transport project focused on making real-time bus information more accessible in Tier 2 and Tier 3 cities.

- Uses a **human-as-sensor** approach to collect and share bus status updates.
- Planned capabilities include live tracking, broadcast mode, offline-friendly access, smart search, and community trust signals.
- Currently in development.

**Tech:** React Native · Firebase Realtime Database · Cloudflare R2

### 🛡️ SentinelAI — Multi-Agent Threat Detection
A cybersecurity project exploring autonomous threat detection and guided remediation across system telemetry and security signals.

- Integrates security monitoring and endpoint telemetry tools with detection rules and agent-based analysis.
- Exploring a stack that includes FastAPI, LangGraph/LangChain, Wazuh, OSQuery, Sigma/YARA rules, PostgreSQL, and local language models.

**Tech:** Python · FastAPI · LangGraph · Wazuh · PostgreSQL · Docker

### 🌱 KrishiGo — Gamified Sustainable Farming
A mobile app concept to encourage sustainable farming through accessible, community-oriented learning.

- Missions, sustainability scoring, a community feed, offline-first experiences, and Malayalam-language support.
- Exploring AI-assisted guidance for farmers.

**Tech:** React Native · Expo · Firebase · Gemini API
